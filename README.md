# Wissenslandkarte Informatik – redaktioneller Prototyp

Entwickelt von Ibtissam Hommada. Eigenständiger Prototyp, kein offizielles Produkt der Hochschule Niederrhein.

## Start
`index.html` in Chrome, Edge oder Firefox öffnen. Die Anwendung läuft offline.

## Umfang
Fünf Module (MA1, GDI, PE1, WIN, DR1), Graph, Suche, Filter, Moduldetails, Fortschrittsexport.

## Hinweis
Fachliche Modulangaben beruhen auf bereitgestellten Modulbeschreibungen von 2019. Beziehungen sind didaktische Vorschläge. Design ist keine offizielle Hochschulvorlage; es werden keine geschützten Schriftdateien oder Logos mitgeliefert.
